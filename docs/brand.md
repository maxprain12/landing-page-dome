# Marca landing

Los tokens de esta landing viven en `src/layouts/Layout.astro`. Tipografía Inter. Para pantallas de producto, el kit de desktop está en el repo hermano [dome/docs/brand](https://github.com/maxprain12/dome/tree/main/docs/brand).

Blog, manuales, contacto y pricing reutilizan el mismo fondo (`NoisyGradient`), botones pill y reveals GSAP. Hex solo en `:root`. Capturas de producto: `public/dome-recursos-landing/`. Si un post no trae `cover`, la landing usa una portada abstracta de `public/covers/` (zinc, lima, lavanda). El cuerpo editorial es Markdown portable (imágenes, listas y citas), el mismo que publica Dome CMS.
