# Accesibilidad

- Un `h1` por página y `<main id="main-content">`.
- Foco visible en `.btn` y nav (`:focus-visible`).
- Honrar `prefers-reduced-motion` (GSAP y `scroll-behavior`).
- Nav desktop: megamenús con botón `aria-expanded`, cierre con Escape y click fuera.
- Nav móvil: panel con `details` anidados; no ocultar links sin alternativa accesible.
- `pnpm run check:a11y` + `pnpm run test:e2e` (axe crítico nuevo = 0; `aria-required-children` del carousel de Benefits está en ratchet).
