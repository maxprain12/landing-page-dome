# Dome: capacidades y mapa competitivo

Revisión: 6 de noviembre de 2026. Base: web, catálogo de funciones y manuales de Dome; páginas oficiales enlazadas en cada comparativa de `/conectores`.

## Qué se puede hacer hoy con Dome según la web

| Área | Capacidad documentada | Condición o límite que conviene explicar |
| --- | --- | --- |
| Biblioteca | Reunir archivos, notas y recursos en carpetas por proyecto; buscar texto. | La búsqueda semántica exige embeddings e indexación configurados. Una imagen sin texto extraído no es un documento indexado. |
| Documentos | Crear y editar notas Markdown con listas, enlaces, tablas e imágenes; conservar archivos en su formato. | No se presenta como editor colaborativo de Word o Google Docs. |
| Many | Preguntar por recursos o un proyecto, revisar referencias y usar herramientas autorizadas. | Hay que configurar proveedor, credenciales y modelo; búsqueda documental, voz y web se configuran por separado. |
| Agentes | Crear agentes especializados y equipos con supervisor. | Un agente solo puede usar herramientas y cuentas habilitadas; instalarlo no garantiza el resultado. |
| Workflows | Encadenar pasos y programar tareas con resultado revisable. | Las plantillas iniciales abren un canvas sin nodos preconfigurados; las tareas locales requieren Dome disponible. |
| Estudio | Preparar contenido generado a partir de objetivo, formato y fuentes, y revisar el resultado. | La modalidad y el formato de exportación dependen del proveedor, modelo y herramienta; la web no documenta una equivalencia general con PowerPoint o Canva. |
| Aprendizaje | Convertir documentos en tarjetas y quizzes con fuentes e historial. | Hace falta texto accesible y Many configurado. |
| Integraciones | Conectar correo, calendario, servicios sociales, MCP y GitHub; leer primero y aprobar acciones externas. | Dependen de permisos, credenciales y del servicio conectado. |
| Publicación | Dome CMS prepara entradas Markdown para un sitio Astro y permite revisar el commit antes de publicarlo. | Requiere complemento, repositorio compatible y permiso de escritura. |
| Dispositivos | Companion permite pedir a Many desde iPhone a través del Mac; extensión de navegador guarda contenido. | Companion y sync son conexiones distintas. |

**Precisión editorial:** la solicitud menciona documentos científicos, presentaciones e imágenes sociales. La web sustenta el trabajo con PDFs y contenido generado desde Estudio, pero no demuestra un flujo especializado de validación científica ni formatos finales universales. Las fichas comparativas hablan de fuentes, revisión y compatibilidad de proveedor sin prometer funciones no documentadas.

## Lectura del mercado

| Necesidad del comprador | Alternativas más cercanas | Encaje de Dome |
| --- | --- | --- |
| Documentar y planificar en equipo | Notion, ClickUp | Biblioteca local y Many sobre recursos; Notion y ClickUp tienen estructuras compartidas de tareas más completas. |
| Producir documentos y presentaciones de oficina | Google Workspace, Microsoft 365 Copilot | Preparación contextual en Dome; las suites mantienen ventaja en formatos nativos y coedición. |
| Investigar y estudiar con fuentes | NotebookLM | Proyectos y archivos locales, tarjetas, quizzes y Many; NotebookLM destaca en formatos de investigación y cuadernos. |
| Crear piezas visuales | Canva | Dome ayuda a preparar contenido desde documentos; Canva ofrece el editor visual y las plantillas. |
| Seguir desarrollo y código | GitHub Projects | Dome añade documentos, personas y acciones de Many alrededor del proyecto. Git es control de versiones y GitHub Projects es la comparación de seguimiento adecuada. |
| Notas Markdown locales | Obsidian | Ambos usan archivos locales; Dome añade biblioteca de otros recursos, Many, agentes e integraciones. |

La diferenciación defendible de Dome es **reunir fuentes locales de un proyecto y poner Many a trabajar sobre ellas con proveedor y permisos configurables**. No conviene afirmar que la IA incorporada sea exclusiva: Notion AI, ClickUp Brain, Gemini, Copilot y NotebookLM ya responden, redactan o generan artefactos.

## Prioridad de las comparativas

1. **Notion y ClickUp:** mayor coincidencia entre proyectos, documentos, tareas e IA.
2. **NotebookLM:** alternativa más directa para preguntar por PDFs, investigar y estudiar.
3. **Google Workspace y Microsoft 365 Copilot:** compradores que esperan documentos y presentaciones finales; explicar las diferencias de formato y colaboración.
4. **Canva:** solapamiento en el contenido visual, con una frontera clara en edición y plantillas.
5. **GitHub Projects:** seguimiento de desarrollo; evitar equiparar Dome con Git o prometer reemplazar PRs.
6. **Obsidian:** comparación natural para quien elige una bóveda Markdown local.

Las ocho fichas públicas incluyen enlaces a sus fuentes oficiales y fecha de revisión. Se deben releer al cambiar el producto de Dome o el de un competidor.
