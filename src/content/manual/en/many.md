Chat with your resources and review actions prepared by Many.

## Requirements

- A provider with valid credentials or an accessible Ollama server.
- An available model for that provider.

## Steps

1. Open Settings → AI and configure the conversation provider, credentials and model.
2. Save and check the connection. The check may consume provider usage.
3. Open Many and supply the resource or project it should use. Make a concrete request and review references.
4. Configure document search, voice and web search separately if needed. Review details before approving an external action.

## Expected result

Many responds using the selected model and tools authorized for the task.

## If something fails

If the connection fails, check credentials, model, quota and server address. For local Ollama, check that the server is running. A working conversation connection does not automatically configure embeddings.
