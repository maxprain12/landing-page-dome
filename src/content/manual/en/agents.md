Specialize instructions and tools for repeated tasks.

## Requirements

- Configured Many.
- Resources and tools needed for the task.

## Steps

1. Open Agents and create an agent or install one from Add-ons.
2. Review its instructions, model and tools. Limit access to what the task needs.
3. Open a conversation with the agent and provide the goal and resources.
4. For coordinated work, configure a team with a supervisor and specialized agents. Review the result and pending actions.

## Expected result

The agent retains its configuration; the team coordinates work through its supervisor.

## If something fails

If a task cannot run, check enabled tools and connected accounts. Installing an agent does not connect services or guarantee a task result.
