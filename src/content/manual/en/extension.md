Capture pages, write notes and save contacts from the browser.

## Requirements

- Dome running on the same computer.
- The extension installed in a supported browser.
- Configured Many for AI actions.

## Steps

1. Check the extension page and use your browser link if the listing is available.
2. Open Settings → Browser extension in Dome and generate a pairing code.
3. Open the extension panel, enter the code and choose the project.
4. Use Capture to save a page, Notes to edit or insert a selection with its source, and Contacts to review details before saving.
5. Review page actions proposed by Many before approving. Save the draft before switching notes.

## Expected result

Content is saved in the Desktop project through the local bridge. Many uses the provider configured in Dome.

## If something fails

If it cannot connect, check that Dome is running and pair again with a new code. Review site permissions. For a note conflict, keep the draft and use the panel recovery options.
