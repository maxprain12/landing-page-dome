Write in Markdown and keep your document context.

## Requirements

- A note in a project.

## Steps

1. Create a note or open an existing one in a tab.
2. Write the title and content; use formatting tools for lists, links, tables and images.
3. Open Markdown mode when you need to review the source syntax.
4. Check the save status before closing. For CMS entries, edit collection, language and publication from the CMS entry.

## Expected result

The note is saved in the vault and can be used as Many context.

## If something fails

If the editor reports a conflict or save failure, keep the draft and resolve the message before switching entries. For complex MDX or HTML, review source mode.
