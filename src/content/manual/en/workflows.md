Connect steps and schedule tasks with reviewable results.

## Requirements

- Many and necessary tools configured.
- Dome running to execute scheduled local tasks.

## Steps

1. Install a template from Add-ons or open the workflow canvas.
2. The bundled starter templates open a canvas without preconfigured nodes. Add and configure nodes, connections and input data before running.
3. Run a test and check results and errors.
4. In Automations, configure the agent, instruction, schedule and output destination. Enable it after reviewing the configuration.

## Expected result

The workflow runs its configured sequence. The automation performs the task on schedule while Dome is available.

## If something fails

If a result is missing, check whether the automation is enabled, its schedule and computer availability. Review history before repeating an action with external effects.
