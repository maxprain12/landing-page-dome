Start with a project, a resource and a first conversation.

## Requirements

- An installer for your operating system.
- A test file you can import.

## Steps

1. Download Dome from the download page and install the version for your computer.
2. Open Dome and create a project for your documents. Import a PDF or create a note.
3. Open the resource in a tab and check that you can read it.
4. To chat with Many, configure a provider and model in Settings → AI.

## Expected result

The resource is available in the project. You can work with notes and files before configuring AI.

## If something fails

If import fails, check the format and file access. If Many does not respond, continue with the Many setup guide.
