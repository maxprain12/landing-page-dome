Organize resources by project and find information in context.

## Requirements

- A project and files or notes.
- An embeddings provider configured for semantic search.

## Steps

1. Select the project and destination folder in the sidebar.
2. Import your files or create a note. Open the resource to review its content.
3. Organize resources in folders and use recognizable names.
4. Search by text; for semantic queries configure document search in Settings → AI and check indexing in Settings.

## Expected result

Files retain their format and notes are saved as Markdown in the project vault.

## If something fails

If a resource is missing from a Many response, check the project, text extraction and indexing status. An image without extracted text is not an indexed document.
