The library is the local store for notes, PDFs, video, audio, and URLs. Many does not invent sources: it works on what you imported and indexed.

1. **Import.** Drag a file, use the + button, or the command palette to add a resource.
2. **Wait for the index.** The Ready for AI badge appears when Many can work on the text.
3. **Ask with the resource open.** Many searches and cites from what is already on your disk.

### From file to Ready for AI

## How a resource gets in

You can drag a file, use the **+** button, or the command palette. The material stays in application storage, not on a Dome drive by default. Organize by project if it helps; the index remains local.

![Library resource detail with visible metadata.](/dome-recursos-landing/dome-library-detail-light-es-primary-landscape.png)

*A PDF in the local library, ready for search and for Many.*

## Ready for AI

The **Ready for AI** badge means the resource is indexed enough for Many to retrieve it. Extractable text from a PDF or note is usually indexed locally. Scanned PDFs and images may need a vision model from the provider you configured.

> **Do not promise magical indexing.** If the file has no text, Many cannot cite it until there is a transcript or a vision pass. That does not make Dome local-only.

## Ask with the resource open

Open the file and ask. Many can search the library and return a brief with citations. The natural next step is to relate that resource to a [person](/en/manual/contacts) or request an [email with approval](/en/manual/email-and-social).
