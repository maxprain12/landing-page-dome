Add plugins, agents, workflows, skills and MCP servers.

## Requirements

- Dome installed.
- Specific requirements of the selected add-on.

## Steps

1. Open Add-ons in Dome or a public catalog entry and select Open in Dome.
2. Filter by category and review description, requirements and permissions.
3. Install or update from the entry. Configure plugins in Settings → Plugins; MCP and skills have their own sections.
4. Check Installed to review add-ons you already have. Keep personal sources in the existing configuration.

## Expected result

The add-on is installed or configured through its specific mechanism. Opening an entry from the website does not install it automatically.

## If something fails

If the link does not open Dome, download or update Desktop and find the entry manually. If an add-on is unavailable in your version, check for updates. The bundled catalog remains available offline; downloading dependencies may need Internet.
