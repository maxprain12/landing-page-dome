Captura páginas, escribe notas y guarda contactos desde el navegador.

## Requisitos

- Dome abierto en el mismo ordenador.
- Extensión instalada en un navegador compatible.
- Many configurado para acciones de IA.

## Pasos

1. Consulta la página de extensión y utiliza el enlace de tu navegador si la publicación está disponible.
2. Abre Ajustes → Extensión de navegador en Dome y genera un código de emparejamiento.
3. Abre el panel de la extensión, introduce el código y elige el proyecto.
4. Utiliza Capturar para guardar una página, Notas para editar o incorporar una selección con fuente y Contactos para revisar los datos antes de guardar.
5. Revisa las acciones que Many propone sobre una página antes de aprobarlas. Guarda el borrador antes de cambiar de nota.

## Resultado esperado

El contenido se guarda en el proyecto de Desktop mediante el puente local. Many utiliza el proveedor configurado en Dome.

## Si algo falla

Si no conecta, comprueba que Dome esté abierto y vuelve a emparejar con un código nuevo. Revisa permisos del sitio. Ante un conflicto de nota, conserva el borrador y usa las opciones de recuperación del panel.
