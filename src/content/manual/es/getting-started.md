Empieza con un proyecto, un recurso y una primera conversación.

## Requisitos

- Instalador para tu sistema operativo.
- Un archivo de prueba que puedas importar.

## Pasos

1. Descarga Dome desde la página de descargas e instala la versión correspondiente a tu equipo.
2. Abre Dome y crea un proyecto para tus documentos. Importa un PDF o crea una nota.
3. Abre el recurso en una pestaña y comprueba que puedes leerlo.
4. Para conversar con Many, configura un proveedor y un modelo en Ajustes → IA.

## Resultado esperado

El recurso queda disponible en el proyecto. Puedes trabajar con notas y archivos antes de configurar IA.

## Si algo falla

Si falla una importación, comprueba el formato y el acceso al archivo. Si Many no responde, continúa con el manual de configuración de Many.
