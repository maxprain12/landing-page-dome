Escribe en Markdown y conserva el contexto de tus documentos.

## Requisitos

- Una nota dentro de un proyecto.

## Pasos

1. Crea una nota o abre una existente en una pestaña.
2. Escribe el título y el contenido; utiliza las herramientas de formato para listas, enlaces, tablas e imágenes.
3. Abre el modo Markdown cuando necesites revisar la sintaxis original.
4. Comprueba el estado de guardado antes de cerrar. Para entradas CMS, edita colección, idioma y publicación desde la ficha del CMS.

## Resultado esperado

La nota queda guardada en la bóveda y puede utilizarse como contexto de Many.

## Si algo falla

Si el editor avisa de un conflicto o de un fallo de guardado, conserva el borrador y resuelve el aviso antes de cambiar de entrada. Para contenido MDX o HTML complejo, revisa el modo fuente.
