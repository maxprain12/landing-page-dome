Conversa con tus recursos y revisa las acciones que Many prepara.

## Requisitos

- Un proveedor con credenciales válidas o un servidor Ollama accesible.
- Un modelo disponible para ese proveedor.

## Pasos

1. Abre Ajustes → IA y configura el proveedor de conversación, sus credenciales y el modelo.
2. Guarda y comprueba la conexión. La comprobación puede consumir uso del proveedor.
3. Abre Many y aporta el recurso o proyecto que debe usar. Haz una petición concreta y revisa las referencias.
4. Configura búsqueda documental, voz y búsqueda web por separado si las necesitas. Revisa los detalles antes de aprobar una acción externa.

## Resultado esperado

Many responde con el modelo seleccionado y usa las herramientas autorizadas para la tarea.

## Si algo falla

Si falla la conexión, comprueba credenciales, modelo, cuota y dirección del servidor. Con Ollama local, verifica que el servidor esté activo. Una conexión de conversación válida no configura automáticamente embeddings.
